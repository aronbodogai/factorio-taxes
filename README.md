# Factorio Taxes

A vanilla-compatible Factorio 2.0 scenario ("soft mod") that adds a recurring
tax obligation to the game. A pre-placed, indestructible rail line and station
exist at map generation. Periodically a tax train arrives, demands a quantity of
items or fluids, and gives the player a limited loading window. Shortfalls are
punished with a proportional biter attack.

* Factorio version: 2.0.77
* Requires DLC: no (no Space Age, no elevated rails, no quality)
* Delivery form: scenario (server-side only, no client mod download)

See `docs/DESIGN.md` for the specification and `PROGRESS.md` for task status.
